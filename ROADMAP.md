# Roadmap

## Now (v0.2)

- Local HTTP + MCP + OpenAPI
- iCloud preset and generic IMAP/SMTP
- Multi-account pools
- Rules, optional sweeps, folder profiles
- SMTP send behind explicit opt-in

## Next

- OAuth for Gmail / Outlook / Microsoft 365 (not required for iCloud or generic IMAP)
- Attachment download to a local directory (still no public expose)
- Watch / IDLE push instead of poll-only sweeps
- Packed installers / Homebrew formula
- Per-rule account filters in the init wizard

## Not planned

- Multi-tenant SaaS or public bind by default
- AppleScript / Mail.app automation
- launchd as the default start path
- IMAP APPEND as a send path (SMTP only)
